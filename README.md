### hey, I'm toasty

I build low-level tooling — mostly reverse engineering, binary analysis, and the kind of stuff that involves reading a hex dump before breakfast. Most recently I've been building [exe-decompiler](https://github.com/woahtoasty/exe-decompiler), a Windows executable decompiler written from scratch: a PE parser, a CLR metadata reader, a CIL-to-C# reconstructor, an x86/x64-to-pseudo-C engine, and a CPython bytecode decompiler, no external tools required.

I like projects where the interesting part is figuring out *how* something works, not just gluing APIs together.

**currently:**
- Improving native code recovery (control flow reconstruction, calling convention detection, switch-table recognition)
- Extending Python bytecode decompilation across interpreter versions
